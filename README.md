# Campus SRun Guardian

当前测试版：**0.1.1-beta.1**。下载 [Windows 发布包](https://github.com/Jiajun-H/CampusSrunGuardian/releases/download/v0.1.1-beta.1/CampusSrunGuardian-0.1.1-beta.1.zip)，或查看 [更新记录](CHANGELOG.md)。

一个面向 ZUEL 校园网的 Windows 图形控制面板和自动认证检查工具。默认门户是 `10.175.100.48`，自动检查只在安装时连接的 Wi-Fi 或名称以 `zuel` 开头的 Wi-Fi 上运行。

安装后，Windows 会在开机、校园 Wi-Fi 网络事件和五分钟兜底时间触发一次短检查；每次检查结束后程序就退出。认证已经在线时不会重复登录，检测到掉线时才会尝试恢复。

## 普通用户：下载与首次设置

1. 从 GitHub Releases 下载最新的 `CampusSrunGuardian-版本号.zip`，解压到一个长期保留的文件夹。
2. 双击 `CampusSrunGuardianControlPanel.exe`，或双击 `Start-CampusSrunGuardian.cmd`。Windows 显示权限提示时选择“是”。**不需要手动打开 PowerShell 或输入命令。**
3. 在控制面板中选择“设置 / 更换账号”，填写校园网账号、可选后缀和密码。
4. 连接校园 Wi-Fi，选择“安装自动检查”。安装器会核对门户、记录当前 Wi-Fi 并设置自动任务。
5. 安装完成后，可以从 Windows“开始”菜单打开“校园网自动认证”。关闭控制面板不会停止已安装的自动检查。

请保留解压后的程序文件夹，直到安装完成。开始菜单入口安装在 `C:\Program Files\CampusSrunGuardian`，控制面板和使用指南会一并安装。

## 从旧版本升级

1. 下载并解压新版 ZIP，关闭旧控制面板。
2. 在新版文件夹中双击 `CampusSrunGuardianControlPanel.exe`，允许 Windows 管理员提示。
3. 选择“修复自动检查”，更新已安装程序、控制面板和开始菜单入口。修复完成后自动检查会开启。
4. 之后从开始菜单打开“校园网自动认证”，标题栏会显示版本号。

已保存的加密账号会继续使用，无需重新配置。新版没有自动下载更新功能，升级需要执行上述步骤。

## 图形界面导览

### 顶部：校园网状态

- **校园网已连接**：认证正常，程序不会重复登录。
- **校园网认证已掉线**：自动检查会尝试恢复；也可以点“立即检查并尝试恢复”。
- **暂时无法读取认证状态**：检查 Wi-Fi 后点“刷新状态”。后台会稍后重试。
- **刷新状态**只读取门户状态，不会提交登录。

### 左侧：账号与自动检查

| 按钮 | 用途 |
| --- | --- |
| **设置 / 更换账号** | 保存或更换校园网账号。密码在本机加密保存，不会写进活动记录。 |
| **安装自动检查** | 首次设置任务；已有任务时显示“修复自动检查”。只在允许的 Wi-Fi 上运行。 |
| **暂停自动检查** / **恢复自动检查** | 暂停或恢复计划任务。暂停期间不会自动尝试登录。 |
| **立即检查并尝试恢复** | 先确认再检查；已在线时只报告状态，掉线时提交一次登录请求。 |
| **检查账号设置（不提交登录）** | 比对程序保存的账号与当前网页登录账号，并读取门户诊断记录。不会提交登录。 |
| **卸载自动检查** | 删除自动任务、已安装程序和开始菜单入口；保留账号凭据与运行记录。 |

把鼠标停在按钮上也会看到简短说明。关键操作会先显示确认提示。

### 右侧：最近活动

这里把后台英文状态和常见错误翻译成简明中文，例如“当前已在线，没有重复登录”或“暂时无法连接校园认证门户”。记录会显示完整日期，便于区分旧错误与当前情况。点击“刷新运行记录”可重新读取最近的后台记录；密码和登录令牌不会显示在这里。

点击“打开使用指南”可再次查看本页说明。

## 常见问题

### 双击启动文件后命令窗口一闪而过

`.cmd` 启动器会快速退出；随后应出现控制面板和 Windows 权限提示。也可以直接双击 `CampusSrunGuardianControlPanel.exe`，或从开始菜单打开“校园网自动认证”。如果出现错误对话框，请把完整内容发给项目维护者。

### 如何知道自动检查正在运行？

控制面板左侧会显示“自动检查已开启”或“自动检查已暂停”，并显示账号是否已保存以及最近运行时间。右侧“最近活动”显示易懂的结果。

### 更换账号怎么办？

选择“设置 / 更换账号”，输入新账号和密码并保存。新账号会用于之后的自动检查。

### 网页能登录，自动登录却提示 login_error？

`login_error` 只表示门户拒绝了自动登录请求，不能单凭它认定密码错误。新版会同时保留门户返回的具体错误码和说明；例如 `E6529` 表示认证失败但门户未提供原因。

保持网页登录成功的状态，点“检查账号设置（不提交登录）”。它会比较保存的账号与网页已登录账号，并查询门户最近一条诊断记录。该记录可能是历史记录；账号相同也不能证明保存的密码正确，因为在线状态下程序不会重复提交登录。可以在“设置 / 更换账号”中重新保存刚才网页登录成功的账号密码；下次自然掉线后再看结果。不要为验证主动断开正在使用的远程连接。

门户返回的内部认证域不自动视为账号后缀。学校登录页没有后缀选项，且填写的账号不带 `@` 时，请将程序的后缀留空。重新保存账号时，最近活动会说明这次输入的账号和密码是否与原保存值相同，便于发现早先输入错误；不会显示密码内容。

### 换了校园 Wi-Fi 或忘记保存的 Wi-Fi 会自动连接吗？

程序不会扫描或连接 Wi-Fi。Windows 必须先连上网络；程序只在安装时记录的 Wi-Fi，或名称以 `zuel` 开头的 Wi-Fi（例如 `zuel-dorm`）上检查。

## Wi-Fi 和门户范围

安装时保存当前连接的 SSID。自动检查也接受所有以 `zuel` 开头的 SSID，大小写不敏感。程序不会保存 Wi-Fi 密码，也不会主动断开或连接网络。

## 高级用户：命令行

普通使用不需要这些命令。排查或开发时可在项目目录运行：

```powershell
.\bin\CampusSrunGuardian.exe --status
.\bin\CampusSrunGuardian.exe --configure
.\bin\CampusSrunGuardian.exe --prepare-login
.\bin\CampusSrunGuardian.exe --diagnose
.\bin\CampusSrunGuardian.exe --once
.\Install-StartupTask.ps1
.\Remove-StartupTask.ps1
```

- `--status` 只读查询状态。
- `--configure` 提示输入账号和密码。
- `--prepare-login` 获取挑战并准备字段，不提交登录。
- `--diagnose` 只读比对保存账号和当前网页登录账号，并查询门户诊断记录，需要管理员权限。
- `--once` 在线时不操作；离线时会提交一次登录请求。
- 安装和卸载脚本需要管理员权限。

## 构建

在 Windows PowerShell 中运行 `Build.ps1` 可构建命令行程序和无控制台图形界面启动器。运行 `Package-Release.ps1 -Version '版本号'` 会生成可发布 ZIP 到 `dist\`。

`VERSION` 是发布版本的来源；更新版本号后运行 `Package-Release.ps1` 即可生成对应安装包。构建后可在 Windows PowerShell 5.1 中运行 `tests\Test-Diagnostics.ps1`，核对账号比较、诊断脱敏和活动记录；检查只使用合成数据，不访问校园门户。

## 安全与已知限制

- 凭据使用本机 DPAPI machine-scope 加密；凭据文件 ACL 限制为 LocalService、SYSTEM 和本机管理员。日志不记录密码或登录令牌。
- 门户使用 HTTP。SRun 挑战字段编码不等于传输加密；仅应在可信校园网络中使用。
- 登录成功只有在门户返回成功且随后状态查询确认在线时才会记录为成功。
- 已确认本机双击启动、任务注册、在线查询及保存账号配置一致；真实掉线后的自动恢复仍待验证。本次更新不能视为已解决 `login_error`。不要为了验证而主动断开正在使用的远程连接。
- 事件触发无法覆盖所有静默会话过期情况；五分钟兜底任务会再次检查。若 Windows 未报告网络变化，恢复最多可能延迟约五分钟。
- 此项目目前针对 `10.175.100.48` 和以 `zuel` 开头的 Wi-Fi。其他学校的 SRun 参数与网络规则可能不同。
